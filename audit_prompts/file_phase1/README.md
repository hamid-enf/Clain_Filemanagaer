# سه ممیزی مستقل فاز اول: فایل و ذخیره‌سازی

به هر ایجنت فقط یکی از سه فایل زیر را بدهید؛ هر پرامپت مستقل است و کد هدف را روی commit `78662328e727910eda54cac0b584c32710f24976` ثابت می‌کند. هر سه باید مستقل، بدون آگاهی از یافته‌های یکدیگر، کار کنند. بعد از دریافت هر سه گزارش، می‌توان یافته‌های تکراری را ادغام و تفاوت‌های نتیجه، پوشش و محدودیت‌ها را بررسی کرد.

| ایجنت | پرامپت | خروجی خواسته‌شده |

صوت، تصویر، ویدئو و ذخیره‌سازی رسانه از هر سه ممیزی خارج‌اند. هیچ تست عملی برد یا پیاده‌سازی پورت Zynq خواسته نشده است. از هر ایجنت گزارش فارسی، شاهد قابل بازتولید، تفکیک نقص تأییدشده از فرضیه، محدودیت‌ها و mutation tests خواسته شده است. ممیزی جامع امکان ادعای «بی‌خطا برای همیشه» نمی‌دهد؛ معیار پایان باید بر شواهد و ریسک‌های باقی‌مانده تکیه کند.

کار مستقل عامل اصلی در `audit_reports/FILE_PHASE1_INTERNAL.md` ثبت شده است. آن گزارش جایگزین بررسی مستقل ایجنت‌ها نیست. کد هدف شامل اصلاح قبلی rename-over در FatFS است؛ هر ممیز باید آن را خودش راستی‌آزمایی کند.
